- 每个文件通过 `module.exports = { ... }` 显式暴露命名函数，内部辅助函数保持私有不被外部引用。
- 对外暴露的函数对空值/非法输入做防御性处理（如 `format.js` 中 `parseDate` 返回 null、`toCents` 将非法输入归零），保证脏数据不会进入数据库。
- 涉及用户交互的异步操作统一包装为 Promise（如 `location.js` 中的 `getSetting`、`openSetting`、`askForSetting`），以便调用方用 async/await 编排。
- 需要 wx API 的模块在失败路径上给出降级提示而非抛错（如复制失败显示「长按选择」、订阅模板缺失时弹窗说明未配置）。
