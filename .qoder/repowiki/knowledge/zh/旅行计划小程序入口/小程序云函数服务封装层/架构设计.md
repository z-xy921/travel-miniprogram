模块以 `cloud.js` 作为唯一出站通道：所有写操作通过 `wx.cloud.callFunction` 调用名为 `CLOUD_FUNCTION` 的云函数，传入 `{action, payload}` 协议；`call` 负责基础 Promise 包装与结果解析，`run` 在其之上叠加 `showLoading`/`hideLoading` 与失败 toast，并区分 `conflict` 版本冲突码交由页面自行处理。

各业务文件（`user.js`、`trip.js`、`poi.js`、`expense.js`、`notify.js`、`photo.js`）是薄适配器，仅把领域方法映射到 `call('domain.action', ...)` / `run('domain.action', ..., '加载中')`，不携带业务逻辑。依赖方向单向：业务 service → `cloud.js` → 微信小程序云开发 API → 后端云函数；前端页面不直连数据库，权限与成员模型变更只需改服务端。
